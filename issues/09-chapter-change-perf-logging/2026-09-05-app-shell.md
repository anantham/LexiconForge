# App-shell deletion and controlled reader measurement — 2026-09-05

LAT-02 removes unused subscriptions, a ref, a memo, imports and abandoned comments
from `MainApp.tsx`. A no-op job-resume fallback existed solely for an incomplete
mock store; the existing fixture now supplies that real store action instead.
Initialization, automatic-preload triggering and in-flight work warnings remain.

## Evidence

Baseline: `0d5f5ce` (reviewed startup source plus public configuration cleanup).
Candidate: `perf/codex-reader-latency`. Three alternating fresh Chromium contexts
per variant, production builds, 4x CPU throttle, external requests and service
workers blocked. Synthetic fixture: four persisted chapters, two translations each,
80 paragraphs per translation. Timing starts at the actual UI click/change event
and ends after matching translated text plus two animation frames.

| Measurement | Before | After |
|---|---:|---:|
| Chapter lookups during 1,000 unrelated store updates, each run | 2,000 | 0 |
| Cached chapter-change median, nine actions per variant | 252 ms | 222 ms |
| Translation-version-change median, three actions per variant | 60 ms | 55 ms |
| MainApp physical lines | 282 | 199 |
| MainApp JavaScript chunk | 522,418 bytes | 521,479 bytes |
| Explicit `any` casts in MainApp | 2 | 0 |
| MainApp function cyclomatic complexity | 10 | 10 |

The unused translation selector (complexity 10), presence selector (2), fallback
selector branch and no-op helper were deleted rather than extracted. Nine unused
store subscriptions are gone. The deterministic improvement is eliminating unused
work; the small navigation sample does not establish a production-device speedup.
All six contexts rendered correct chapter/version text, had zero page errors, warned
before closing with background work, and allowed closing when idle. Original issue
9's older real-novel trace is not closed by this different fixture.

Existing focused gate: 46/46 app-screen, automatic-translation mediator and image
job/lifecycle tests. TypeScript, production build and scoped lint pass (zero lint
errors; existing warnings). No new unit test mirrors the deleted hooks.

Focused app-shell line coverage is 75.26% → 68.57%, branch coverage 63.46% → 57.89%.
These are the same three app-screen tests against each source. Removing executed
but unused code lowers the percentage; thresholds and assertions were not weakened,
and tests were not added merely to restore the old number. Browser warning checks
cover behavior beyond that narrow unit fixture.

## Reproduce

Use Node 24.19.0 and identical locked dependencies. Build each revision separately,
then run strict-port loopback previews. From the candidate:

```sh
node issues/09-chapter-change-perf-logging/reader-update-probe.mjs http://127.0.0.1:5192 http://127.0.0.1:5193
node node_modules/vitest/vitest.mjs run tests/store/appScreen.integration.test.tsx tests/store/autoTranslateMediator.test.ts tests/store/slices/imageJobsSlice.test.ts tests/store/slices/imageSlice.leak-on-throw.test.ts
```

The probe creates disposable browser contexts and synthetic data; it does not use
credentials, a personal profile, provider calls or canonical user data. Preserve
its JSONL samples with the exact source heads. Real large-library, background-tab
and physical-device latency remain separate acceptance work.
